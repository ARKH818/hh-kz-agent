# Checklist безопасного запуска HH.kz Agent на macOS ARM64

Выполняйте пункты сверху вниз. Не включайте реальные отклики, пока dry-run не проработал без ошибок.

## Подготовка

* [ ] Откройте Terminal.
* [ ] Перейдите в папку проекта через `cd`.
* [ ] Проверьте Homebrew:

```bash
brew --version
```

* [ ] Если Homebrew отсутствует, установите его с официального сайта.
* [ ] Установите Python 3.13:

```bash
brew install python@3.13
```

* [ ] Создайте отдельное Python-окружение:

```bash
"$(brew --prefix python@3.13)/bin/python3.13" -m venv .venv
source .venv/bin/activate
```

* [ ] Проверьте Python:

```bash
python3 --version
python3 -m pip --version
```

* [ ] Установите зависимости:

```bash
python3 -m pip install --upgrade pip
python3 -m pip install -r requirements.txt
python3 -m pip install -r requirements-dev.txt
```

## Browser и Playwright

* [ ] Установите Chromium для Playwright:

```bash
python3 -m playwright install chromium
```

* [ ] Проверьте запуск браузера:

```bash
python3 -m scripts.browser_smoke --backend playwright --no-headless --profile-dir .browser-smoke-profile
```

* [ ] Убедитесь, что браузер запускается без ошибок.
* [ ] Убедитесь, что тестовый запрос возвращает `status=200`.
* [ ] Проверьте, что профиль браузера создаётся в указанной директории.
* [ ] Для первого запуска используйте видимый браузер:

```ini
BROWSER_BACKEND=playwright
BROWSER_HEADLESS=false
BROWSER_PROFILE_DIR=.browser-profile
```

* [ ] Не используйте реальные данные браузерного профиля в Git.

## Telegram

* [ ] Создайте Telegram-бота через официальный `@BotFather`.
* [ ] Сохраните токен только локально.
* [ ] Не добавляйте токен в Git, README, issue или сообщения.
* [ ] Получите свой числовой Telegram User ID.
* [ ] Откройте созданного бота и нажмите Start.
* [ ] Укажите Telegram-параметры в локальном `.env`.

## Локальная конфигурация

* [ ] Создайте `.env` из шаблона:

```bash
cp .env.example .env
```

* [ ] Создайте локальный профиль:

```bash
cp profile.example.yaml profile.yaml
```

* [ ] Откройте `.env` и заполните необходимые параметры:

```ini
TG_BOT_TOKEN=your_telegram_bot_token
TG_USER_ID=your_telegram_user_id

APP_MODE=dry_run
ENABLE_REAL_APPLY=false

BROWSER_BACKEND=playwright
BROWSER_HEADLESS=false
BROWSER_PROFILE_DIR=.browser-profile
```

* [ ] Откройте `profile.yaml`.
* [ ] Заполните `candidate.name`.
* [ ] Заполните `candidate.desired_positions`.
* [ ] Заполните `candidate.experience_summary`.
* [ ] Укажите актуальные технологии и опыт.
* [ ] При необходимости заполните образование, проекты и дополнительную информацию.
* [ ] Укажите `hh.resume_name` точно так, как резюме называется на HH.kz.
* [ ] Укажите хотя бы один поисковый запрос в `hh.search_queries`.
* [ ] Проверьте `hh.areas`.
* [ ] Проверьте фильтры опыта и другие параметры поиска.
* [ ] Заполняйте профиль только достоверными данными.

## Проверка Git и секретов

* [ ] Убедитесь, что `.env` не отслеживается Git:

```bash
git check-ignore .env
```

* [ ] Убедитесь, что `profile.yaml` не отслеживается Git:

```bash
git check-ignore profile.yaml
```

* [ ] Убедитесь, что браузерный профиль не отслеживается:

```bash
git check-ignore .browser-profile
```

* [ ] Не добавляйте в репозиторий:

  * `.env`;
  * `profile.yaml`;
  * `.browser-profile/`;
  * `agent.db`;
  * `agent.log`;
  * backup-файлы;
  * cookies;
  * session-файлы;
  * локальные credentials.

## Проверка конфигурации

* [ ] Проверьте конфигурацию без запуска реального отклика:

```bash
python3 main.py --check-config
```

* [ ] Убедитесь, что конфигурация проходит валидацию.
* [ ] Убедитесь, что Telegram User ID указан правильно.
* [ ] Убедитесь, что `APP_MODE=dry_run`.
* [ ] Убедитесь, что `ENABLE_REAL_APPLY=false`.
* [ ] Убедитесь, что используется нужный browser backend.

## Тестирование

* [ ] Запустите unit-тесты:

```bash
pytest -q
```

* [ ] Проверьте синтаксис Python:

```bash
python3 -m compileall .
```

* [ ] Все тесты должны завершиться без ошибок.
* [ ] Исправьте ошибки тестов до запуска реального приложения.

## Первый запуск

* [ ] Запустите приложение:

```bash
python3 main.py
```

* [ ] В открывшемся браузере вручную войдите в свой аккаунт HH.kz.
* [ ] Если приложение ожидает подтверждения продолжения, подтвердите запуск.
* [ ] Проверьте Telegram-команду:

```text
/status
```

* [ ] Убедитесь, что приложение работает в режиме `dry_run`.
* [ ] Дождитесь получения первой вакансии.
* [ ] Проверьте данные вакансии:

  * название;
  * компания;
  * ссылка;
  * зарплата, если указана;
  * описание;
  * соответствие профилю.
* [ ] Убедитесь, что в dry-run реальный отклик не отправляется.
* [ ] Проверьте `/stats`.
* [ ] Проверьте `/pause`.
* [ ] Проверьте `/resume`.
* [ ] Проверьте `/pending`, если есть ожидающие вакансии.
* [ ] Проверьте `/diagnostics`.
* [ ] Остановите приложение через `Ctrl+C`.

## Проверка SQLite

* [ ] Убедитесь, что файл базы создаётся локально:

```text
agent.db
```

* [ ] Проверьте, что база не добавлена в Git.
* [ ] Проверьте корректность базы:

```bash
sqlite3 agent.db "PRAGMA integrity_check;"
```

* [ ] Результат должен быть:

```text
ok
```

## Резервная копия

* [ ] Создайте директорию для backup:

```bash
mkdir -p backups
```

* [ ] Создайте резервную копию базы:

```bash
sqlite3 agent.db ".backup 'backups/agent-backup.db'"
```

* [ ] Проверьте backup:

```bash
sqlite3 backups/agent-backup.db "PRAGMA integrity_check;"
```

* [ ] Результат должен быть `ok`.
* [ ] Не добавляйте backup в Git.
* [ ] Храните backup отдельно от репозитория.

## Переход к индивидуальному подтверждению

Переходите к этому разделу только после успешного dry-run.

* [ ] Убедитесь, что поиск вакансий работает стабильно.
* [ ] Убедитесь, что дубликаты корректно обрабатываются.
* [ ] Убедитесь, что вакансии сохраняются в SQLite.
* [ ] Убедитесь, что Telegram-карточки отображаются корректно.
* [ ] Убедитесь, что `/pause` и `/resume` работают.
* [ ] Убедитесь, что ошибок браузера и селекторов нет.
* [ ] Убедитесь, что приложение не отправляет отклики самостоятельно.

Измените только:

```ini
APP_MODE=approval
ENABLE_REAL_APPLY=true
```

* [ ] Снова проверьте конфигурацию:

```bash
python3 main.py --check-config
```

* [ ] Запустите приложение:

```bash
python3 main.py
```

* [ ] Для каждой вакансии отдельно проверьте:

  * название;
  * компанию;
  * ссылку;
  * резюме;
  * данные вакансии;
  * форму отклика.
* [ ] Нажимайте `Откликнуться` только после ручной проверки вакансии.
* [ ] Используйте `Пропустить`, если вакансия не подходит.

## Реальный отклик

Перед каждым реальным откликом должна выполняться цепочка:

```text
Новая вакансия
        |
        v
SQLite
        |
        v
Telegram
        |
        v
Ручная проверка
        |
        v
Откликнуться
        |
        v
HH.kz
        |
        v
Результат
        |
        v
SQLite
```

* [ ] Проверьте, что отклик инициирован именно вашим Telegram User ID.
* [ ] Проверьте, что вакансия не была обработана ранее.
* [ ] Проверьте, что приложение не выполняет повторный отклик.
* [ ] После отправки проверьте итоговый статус.
* [ ] Проверьте запись результата в SQLite.
* [ ] Проверьте уведомление в Telegram.

## Если что-то пошло не так

* [ ] Выполните:

```text
/pause
```

* [ ] Не запускайте приложение повторно сразу после неизвестной ошибки отклика.
* [ ] Проверьте `agent.log`, не публикуя его целиком.
* [ ] Проверьте `/pending`.
* [ ] Проверьте `/stats`.
* [ ] Проверьте `/diagnostics`.
* [ ] Если статус вакансии остался `applying`, сначала вручную проверьте HH.kz.
* [ ] Не отправляйте повторный отклик, пока не установлено состояние предыдущего.
* [ ] При проблемах с браузером остановите приложение.
* [ ] Сохраните текущий браузерный профиль перед экспериментами.
* [ ] Для нового профиля можно переименовать старый:

```bash
mv .browser-profile .browser-profile.backup
```

* [ ] После этого запустите приложение снова с:

```ini
BROWSER_HEADLESS=false
```
